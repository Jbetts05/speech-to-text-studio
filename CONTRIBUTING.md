# Contributing

Read [AGENTS.md](AGENTS.md) before contributing.

- Put reusable behavior in platform core and task-specific behavior in a benchmark pack.
- Use only synthetic or clearly redistributable fixtures.
- Add tests for contracts, evidence, failures, accessibility, and generated assets.
- Run all quality gates.
- Explain schema/version changes and pricing provenance in the pull request.
- Never add credentials, cloud IDs, local paths, deployment state, generated results, or
  a `Co-authored-by` trailer.
